# План розробки повнофункціонального інтернет-магазину "YANTI TITANIUM"

Створення повноцінного веб-додатку інтернет-магазину преміальних титанових прикрас для пірсингу **YANTI TITANIUM** на базі **Next.js 15 (App Router), TypeScript, Tailwind CSS, Lucide React та Zustand** з абсолютно клікабельним функціоналом без заглушок.

---

## 1. Архітектурні рішення та UX-функціонал

1. **Інтерактивна картка товару (Single Product Experience):**
   - Живий вибір товщини (`Gauge: 1.2mm / 1.6mm`) та розміру (`6mm / 8mm / 10mm`) з динамічним оновленням залишків та ціни.
   - **Інтерактивний візуалізатор анодування:** вибір кольору (Silver, 65V Gold, Rose Gold, Deep Purple, Ice Blue, Bronze) змінює відтінок прикраси/бейдж у реальному часі.
   - **Стерилізація в автоклаві:** інтерактивний перемикач `+50 ₴` з інформаційним модальним вікном про автоклав і крафт-пакети.
   - **Сумісні накрутки (Upsell):** клікабельні додаткові топи з можливістю додати в один клік.

2. **Повнофункціональний кошик (Slide-over Cart Drawer):**
   - Керування кількістю, видалення, перемикач стерилізації безпосередньо в кошику.
   - Живий перерахунок загальної суми, збереження стану в `localStorage` через Zustand.
   - Швидкий перехід до оформлення замовлення.

3. **3-кроковий Guest Checkout (Оформлення без реєстрації):**
   - **Крок 1: Контакти** (Ім'я, Прізвище, Телефон з маскою +380, Email).
   - **Крок 2: Нова Пошта** (Вибір міста з автокомплітом, вибір відділення/поштомату або кур'єр).
   - **Крок 3: Оплата** (Накладений платіж при отриманні, Онлайн карткою, IBAN реквізити).
   - Формування замовлення та редирект на красивий екран успіху `Checkout Success` з номером замовлення.

4. **Інтеграція сповіщень у Telegram:**
   - Server Action для запису замовлення та миттєвої відправки форматованого повідомлення у Telegram-канал/чат.

5. **Панель керування замовленнями (/admin):**
   - Перегляд усіх замовлень у реальному часі.
   - Фільтрація за статусами (`Нове`, `В обробці`, `Відправлено`, `Виконано`, `Скасовано`).
   - Клікабельна зміна статусу та перегляд детального складу по кожній прикрасі.

6. **Google Merchant XML Feed (`/api/feed/google-merchant`):**
   - Робочий endpoint для генерації дійсного XML-каталогу з цінами у UAH, фотографіями та наявністю.

## 2. Запропонована структура файлів

### Конфігурація та стилі
- `package.json`: Next.js 15, React 19, Tailwind CSS, Lucide React, Zustand, clsx, tailwind-merge.
- `tailwind.config.ts`: Палітра титанового срібла, глибокого графіту, темний студійний мінімалізм.
- `app/globals.css`: Стилі сріблястого сяйва, скролбари, анімації палітри анодування.

### База даних та мок-провайдер
- `lib/data/mockProducts.ts`: Багатий набір реалістичних товарів преміум-титану (Лабрети з кристалами Swarovski, Клікери з паве, Безрізьбові топи, Штанги) з детальними фото, варіантами розмірів та цінами.
- `lib/store/useCartStore.ts`: Повноцінний Zustand-стор для кошика з персистентністю в браузері.
- `lib/store/useOrderStore.ts`: Стор для збереження та керування замовленнями (для демонстрації та адмінки).
- `lib/actions/order.ts`: Server Action для обробки оформлення та відправки в Telegram.

### UI & Компоненти
- `components/layout/Header.tsx`: Чорний хедер, срібний логотип зі сяйвом, пошук, лічильник кошика, мобільне меню.
- `components/layout/Footer.tsx`: Студійний темний футер з сертифікатами ASTM F-136, навігацією та контактами.
- `components/shop/ProductCard.tsx`: Картка з живими зразками кольорів, швидким додаванням та макро-фото.
- `components/shop/CartDrawer.tsx`: Повністю робочий висувний кошик з регулюванням кількості та опцій.
- `components/shop/AnodizationPicker.tsx`: Інтерактивний вибір напруги/кольору анодування.
- `components/shop/VariantSelector.tsx`: Вибір розмірів та калібру.
- `components/shop/SterilizationModal.tsx`: Інформаційне модальне вікно про медичну автоклав-стерилізацію.

### Сторінки (App Router)
- `app/page.tsx`: Головна сторінка з Hero-секцією, категоріями, бестселерами, перевагами титану та відгуками.
- `app/catalog/page.tsx`: Каталог товарів з фільтрацією за категорією, калібром (gauge), кольором та сортуванням за ціною.
- `app/product/[slug]/page.tsx`: Сторінка товару з галереєю, перемикачем кольорів, апсейлом топів та додаванням у кошик.
- `app/checkout/page.tsx`: Інтерактивне 3-крокове оформлення замовлення з валідацією.
- `app/checkout/success/page.tsx`: Сторінка підтвердження замовлення.
- `app/admin/page.tsx`: Повноцінна адмін-панель замовлень з можливістю змінювати статуси та фільтрувати.
- `app/about/page.tsx`, `app/delivery/page.tsx`, `app/contacts/page.tsx`: Інформаційні сторінки магазину.
- `app/api/feed/google-merchant/route.ts`: XML фід для Google Merchant Center.

## 3. План верифікації

### Автоматична перевірка:
- `npm run build` або `npx next build` для підтвердження відсутності помилок компіляції TypeScript та синтаксису.
- Запуск локального сервера та тестування всіх маршрутів.

### Ручна верифікація (End-to-End):
1. **Каталог & Пошук:** Перевірка фільтрації за категоріями, розмірами, введення у рядок пошуку.
2. **Товар:** Клік по варіантах калібру, вибір кольору анодування, увімкнення галочки "Стерилізація (+50 ₴)" -> клік "Додати в кошик".
3. **Кошик:** Перевірка відкриття `CartDrawer`, зміна кількості, автоматичний перерахунок суми.
4. **Checkout:** Заповнення форми замовлення (Контакти -> Нова Пошта -> Оплата) -> Відправка замовлення.
5. **Success & Admin:** Перехід на сторінку успіху, перевірка появи нового замовлення в `/admin` зі зміною статусу.
